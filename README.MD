
# 🌸 Iris Species Prediction App (Streamlit Deployment)

## 📌 Project Overview
This project demonstrates an end-to-end Machine Learning deployment using Streamlit.  
A trained Random Forest model predicts the species of an Iris flower based on user input features.

The application is deployed as an interactive web app.

---

## 🎯 Problem Statement
Given flower measurements:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Predict the Iris species:
- Setosa
- Versicolor
- Virginica

---

## 📊 Dataset
The dataset used is the built-in Iris dataset from Scikit-learn.

- 150 samples
- 3 classes
- 4 numerical features

---

## 🤖 Model
- Algorithm: Random Forest Classifier
- Library: Scikit-learn
- Model saved using: joblib

---

## 🚀 Deployment
The model is deployed using:

- Streamlit (Frontend UI)
- Streamlit Community Cloud (Hosting)

Users can:
- Input feature values
- Click Predict
- View prediction and confidence score
